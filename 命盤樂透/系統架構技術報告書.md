# 天機合參 · 命盤樂透整合系統 - 專業技術與架構報告書

## 一、 系統概述 (System Overview)
「天機合參 · 命盤樂透整合系統」是一套創新且全面的決策輔助平台，結合了**傳統東方命理（生辰八字、五行磁場）**、**現代大數據統計**與**數學組合學（聰明包牌矩陣）**。本系統旨在為使用者提供全方位的人生運勢導航與精準的彩券選號策略，將抽象的命理概念轉化為具體的數據化指標。

## 二、 核心技術棧與使用框架 (Core Technologies)

本系統採用 Python 作為核心開發語言，並透過整合多個高效能的開源套件來實現複雜的功能架構：

### 1. 前端介面與網頁框架 (Frontend & Web Framework)
*   **Streamlit**: 作為全端應用的核心框架。透過其快速構建資料應用的特性，打造出高度互動式的動態介面。系統中大量運用 `st.session_state` 來管理狀態（如即時選號數量統計），並透過嵌入自定義 CSS 來實現突破原有限制的深色大氣背景、漸層發光按鈕與自適應佈局。

### 2. 資料處理與視覺化 (Data Processing & Visualization)
*   **Pandas**: 系統的數據處理心臟，負責處理歷史開獎紀錄、清洗數據、以及進行冷熱門號碼的頻率統計與分佈計算。
*   **Plotly**: 負責將龐雜的歷史數據與趨勢轉化為直觀的互動式圖表（如長條圖、趨勢圖），讓使用者能一眼看出號碼的活躍程度。

### 3. 大數據獲取與爬蟲引擎 (Data Scraping)
*   **Requests + BeautifulSoup4 + lxml**: 負責即時從外部網站（如台灣彩券官網）抓取最新的大樂透與威力彩開獎數據。透過 lxml 解析器大幅提升 HTML 標籤的解析速度，確保資料庫（SQLite）能隨時保持在最新狀態。

### 4. 命理與曆法運算引擎 (Astrology & Calendar)
*   **lunar_python (農曆/八字運算)**: 負責將使用者的西曆出生日期精準轉換為農曆與天干地支（生辰八字），進而推算個人的五行屬性（金木水火土）。
*   **pyswisseph (瑞士星曆表)**: 提供極高精度的星體運行數據支援，確保命理推算背後的天文曆法基礎具備專業級準確度。

### 5. 機器學習與數據模型 (Machine Learning)
*   **Scikit-learn**: 用於建立選號預測與數據分群模型，透過過往大數據的特徵工程（Feature Engineering），計算並賦予不同號碼在不同週期內的權重分數，實現 AI 智慧選號推薦。

## 三、 系統核心模組與演算法實作 (Core Modules & Algorithms)

### 1. 歷史大數據與冷熱統計模組
系統透過爬蟲抓取歷史開獎數據後，存入本地端的 `lottery_data.db` (SQLite)。分析模組會根據近期開出頻率，計算出「極熱門」、「熱門」、「溫和」與「冷門」號碼，讓使用者在選號時具備客觀的數學機率依據。

### 2. 聰明包牌矩陣系統 (Smart Wheeling System)
此模組採用了數學組合設計領域的**最小涵蓋矩陣 (Covering Design)**。
*   **運作原理**: 傳統全餐包牌成本極高。此演算法能將使用者精選的多顆號碼（如 8 顆或 12 顆），透過預先計算好的數學矩陣，拆解成最少注數的組合，並保證在命中特定條件下（如中 4 保 3），一定會有至少一注中獎。大幅降低防禦性包牌的成本。

### 3. 八字五行磁場微調 (AI Resonance)
系統獨創的交叉分析引擎：
*   先透過 `lunar_python` 取得使用者的本命五行屬性。
*   將五行屬性對應到彩券號碼（例如：屬水的號碼可能為 01、06、11 等）。
*   系統會將使用者的「心水自選號碼」與「五行幸運號碼」結合，再過濾掉大數據判定極冷門的號碼，達成**玄學與科學的雙重驗證**。

### 4. 夢境解碼分析系統 (Dream Dictionary)
內建專屬的 `dream_dict.py` 夢境字典資料庫。使用者可輸入夢境關鍵字（如：蛇、火災、水），系統會進行關鍵字匹配與自然語言處理，自動將夢境特徵轉換為高關聯性的幸運號碼，並可無縫匯入包牌系統。

### 5. 即時動態狀態管理 (Reactive UI)
為了解決 Streamlit 原生表單 (`st.form`) 無法即時互動的問題，系統採用了 `st.container` 搭配 `st.session_state` 的動態綁定技術。這使得使用者在「彩券畫記區」點擊核取方塊時，上方標題能「零延遲」即時統計並顯示已選數量，且不會造成區塊錯誤收合，大幅提升了操作流暢度。

---

## 四、 總結 (Conclusion)
本系統成功打破了單純依賴「隨機機率」的樂透應用框架。透過 **Python 強大的資料科學生態系 (Pandas/Scikit-learn)** 負責數據底層，結合 **Streamlit** 打造流暢的使用者體驗，最後融入了 **lunar_python** 的命理運算邏輯，是一套架構完整、邏輯嚴謹且具備高度創新性的複合式決策系統。
